# 依存ライブラリ

## ランタイム

- **Node.js** 20+ (ESM)

## サーバ

| ライブラリ | 用途 |
|---|---|
| **Fastify** 5 | HTTPサーバ |
| **@fastify/static** | SPAの静的ファイル配信 |
| **DuckDB** 1.4 | インメモリSQLエンジン |
| **node-postgres (pg)** 8 | PostgreSQLクライアント |
| **dotenv** | `.env` ファイル読み込み |
| **yaml** | YAMLパース（frontmatter、ブックマーク） |

## SPA (クライアント)

| ライブラリ | 用途 |
|---|---|
| **Svelte** 5 | UIフレームワーク |
| **Vite** 7 | ビルドツール |
| **FullCalendar** 6 | カレンダー表示 |
| **ECharts** 5 | グラフ描画 |
| **CodeMirror** 6 | コード/マークダウンエディタ |
| **markdown-it** 14 | マークダウンレンダリング |
| **PrismJS** 1 | シンタックスハイライト |
| **jSpreadsheet** | CSVスプレッドシート編集 |
| **ical.js** | iCalファイルパース |
| **uuid** | ID生成 |

## インフラ（オプション）

| ソフトウェア | 用途 |
|---|---|
| **Collabora Online** | Officeドキュメント編集（WOPIプロトコル） |
| **Podman** | Collabora Online のコンテナ実行環境 |
