# Javascriptコーディング規約
## 全般

* ES Moduleを使う
  特に理由のない限り、common JSは使わない。使う場合は拡張子を`.cjs`とする
* ESの仕様は互換性に問題がない限り新しいものを選択する
* 関数名、変数名はキャメルケース、ファイル名はケバブケース
  「名前」はスコープの広いものは「フルスペルの単語の接続」で表現したものとし、名前だけで実体がわかるようにする。特に`export`するものについてはこれは絶対要件である
* 手続き定義は const を使った形式にする。すなわち

```
const func = (...) => {
  ...
}
```

である。

## コーディングルール

### 分割規則

* 1つの機能単位(function)は50行程度を目安とし、100行程度を限界とする
  機能単位は単機能にする
* 1つのブロック(`{}`で囲まれたもの)は20行程度を目安とし、50行程度を限界とする
* 上記の「目安」を超えたものは別の機能単位になることを疑い、積極的に機能単位を分割する
* 処理に「名前」がつけられるものは、その「名前」で機能単位を作る
* 複文は悪文

### インデント規則

* インデントは2カラム単位で空白を使う(タブは使わない)
* if に else ifが連なる場合は、
```
if ....{
  ...
} else
if ... {
  ...
} else {

}
```
のようにレベルを揃える

* switch文については以下のように書くこと
```
switch ... {
  case  ...
    ...
    break;
  ...
}
```
すなわち、switchに対してcaseは1タブ下げ、case以下の文はさらに1タブ下げである。

## 留意事項

* 人間の読む文章は全て日本語にすること
  * 生成するドキュメント、コード中のコメント、メッセージ等全て
* console.logやコメントアウトされたconsole.logは、特に指示されない限り勝手に削除しない
